# ASP.NET Web API RESTful

This repository contains my ASP.NET Web API and RESTful API practice
programs, developed using C# and .NET.

## 🚀 Technologies Used

- C#
- ASP.NET Web API
- .NET Framework
- RESTful API
- SQL Server
- ADO.NET
- Entity Framework
- JSON
- Postman
- Visual Studio

## 📚 Topics Covered

- Introduction to ASP.NET Web API
- RESTful API Fundamentals
- HTTP Methods (GET, POST, PUT, DELETE)
- API Routing
- Controllers and Action Methods
- CRUD Operations
- Request and Response Handling
- JSON Data Handling
- HTTP Status Codes
- Model Binding
- Data Validation
- SQL Server Database Connectivity
- Entity Framework
- API Testing with Postman
- Exception Handling

## 🎯 Purpose

The purpose of this repository is to practice RESTful API development,
understand HTTP methods, and improve my backend development skills
using C# and ASP.NET Web API.
